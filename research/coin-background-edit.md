# Обработка монет

Built-in imagegen, background-extraction; transparent_background: true. По одному вызову для каждого исходного файла.

Промпт:

Remove ONLY the background (and any ruler below the coins) to genuine transparency. Keep original coin pixels, every inscription, patina, damage, lighting and irregular edge as faithfully as possible. Do not reconstruct, beautify, sharpen or invent any detail. If two coin faces appear, preserve both side by side in the exact arrangement. Tight crop with small transparent padding. This is an archival website cutout, never a newly designed coin.

Исходники и соответствующие вырезки перечислены в assets/coin-cutouts-attribution.json. Все вырезки сохранены в assets/*-cutout.png. Исходные фотографии сохранены отдельно; генеративная обработка фона не заменяет источник при изучении легенды.
